# v0.3.3 海外服务选择

范围：本地服务目录、分类搜索勾选、预设迁移、规则与 DNS、文档和验证；保留 v0.3.2 已完成内容。后续已获授权提交、推送及 GitHub Pages 部署，发布结果见 RELEASE_v0.3.3.md。
主智能体负责持久化兼容、集成、文档和浏览器验证；core 负责目录与规则及来源；storage 代理负责服务选择页面（沿用代理名称）。子任务继承既有 Terra 配置。
约束：新增项默认关闭；旧四项选择保持；按服务而非云厂商大网段匹配；无节点凭据持久化；服务域名可能共用，界面说明影响。
验收：X/TikTok 等可搜索勾选，规则和 DNS 同步；分类批量操作清晰；迁移不覆盖旧选择；桌面手机操作与回归通过。
状态：本地实现、验证和设置迁移独立复核已完成。

- v0.3.3 共 29 项、6 类服务；新增 25 项默认关闭，原四项默认和保存值保持。

- v0.3.2 旧四项存储迁移、首次加载不覆盖、非法新增字段拒绝已验证；持久化逻辑独立复核通过。
